# Video Assets for Kinya Learn

This directory contains local video files for the Kinyarwanda learning app.

## Video Files Structure:

- `greetings_basic.mp4` - Basic greetings lesson
- `family_members.mp4` - Family members vocabulary
- `numbers_counting.mp4` - Numbers and counting
- `daily_conversations.mp4` - Daily conversation examples
- `pronunciation_guide.mp4` - Pronunciation guide

## Alternative Video Sources:

1. **Local Assets**: Store MP4 files in this directory
2. **Vimeo**: Professional video hosting alternative
3. **Direct Links**: Direct links to MP4 files
4. **Generated Content**: Text-to-speech with visual aids

## Video Specifications:

- Format: MP4 (H.264)
- Resolution: 720p minimum
- Audio: Clear Kinyarwanda pronunciation
- Subtitles: English and Kinyarwanda
- Duration: 3-8 minutes per lesson
